git --version = ele vai verificar a versão/instalação do git no seu pc
git init = inicializa um repositório Git localmente no seu computador
git = sistema de controle de versão

vamos usar só uma vez: git init, 

git config --global user.name 'coloque seu nome aqui' = configura o nome
git config --global user.email 'coloque seu email aqui' = configura o email
git config --global user.name 'coloque seu nome aqui'

git config --list = o comando vai listar as configurações do git

pode ser usado varias vezes:

git status = verifica se estão prontos para serem salvos ou não
git add (algo) = adiciona no pré save
git rm --cached = remove do pré save 
git commit -m 'texto'
